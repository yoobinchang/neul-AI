NEUL FRONTEND v0.2 | Mobile + Parent Mode + Location Preview
=============================================================

This ZIP overlays an existing Next.js 16 app at ~/Desktop/neul-AI/app .
It preserves your Home, Calls, Alerts and Profile features and adds Parent
Mode, a mock pairing dialog, a location-preview tab, and PWA PNG icons.

INSTALL (use a NEW VS Code terminal; leave the original npm run dev open):
    cd ~/Desktop/neul-AI/app
    unzip -o ~/Downloads/neul-parent-upgrade-v02.zip

No npm install required if lucide-react is already installed.
Refresh http://localhost:3000 or restart with npm run dev .

DEMO WALKTHROUGH:
    1. In the Caregiver dashboard, tap Parent Mode (top right).
    2. Tap the large "I'm lost" button in Parent Mode.
    3. If prompted, allow device location for a local-only preview.
    4. Tap "Caregiver view" then "Location" to see the mock map,
       approximate accuracy, coordinates (if permission was given),
       and any note you entered in Parent Mode.
    5. Return to Parent Mode, tap "I'm safe now", then try Pair Device.
       The sample code is 482915; it is NOT real pairing.
    6. Test on a narrow browser window or mobile device.

SAFETY / PRIVACY:
    - No family accounts are paired. Code 482915 is demonstration only.
    - "I'm lost" does NOT send SMS, make a call, notify anyone, or save
      data to Supabase. It only requests browser GPS permission.
    - Coordinates are held in React state in THIS browser tab only.
      They do not persist after refresh and are never uploaded by this code.
    - The on-screen map artwork is ILLUSTRATIVE, not geographic.
    - "Open actual map" is an explicit outbound link to OpenStreetMap:
      opening it transmits the displayed coordinates to that site.
    - "Call Alex" / "Call Mom" are demo interactions only.
    - PWA icons and manifest are included, but offline mode, push,
      emergency delivery, auth, and actual secure pairing are NOT complete.
    - Do not use the demo for real emergency response.

TEST BEFORE PUSHING:
